Format / citation card Required before draft

Required format & citation fields

  • Agency (e.g. Chandler PD, Brownsboro PD, Henderson County SO)
  • Source type — press release / public blotter / on-record officer / court public record
  • Source URL or doc id (or “release emailed YYYY-MM-DD”)
  • Incident date/time (as reported)
  • Location — block/intersection + city (no exact victim home address unless agency released it)
  • Incident type — use agency wording
  • What happened — 2–4 sentences, sourced facts only
  • Names — adults named in official source only; no juveniles
  • Charges / disposition — only if sourced
  • Editor verification — date checked + who checked

Cite the agency on every item. Factual, neutral tone. No unverified tip-line gossip.
